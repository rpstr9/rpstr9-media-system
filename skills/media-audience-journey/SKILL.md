# Perception Flow / Audience Journey

Read [operating boundaries](../../policies/CONSTITUTION.md) and [handoff rules](../../contracts/HANDOFF.md). Use only the current task’s required inputs and references.

## Method
Determine whether the task needs a journey at all. Accept an approved supplied journey after reading its actual current contents. Keep its full source, stages, relationships, evidence and status; do not reconstruct it from a title.

When a Perception Flow Model is requested, load its complete locked external method and required references using [method dependency register](../../registry/method-dependencies.json). Preserve its prescribed states, dimensions and table, language conventions and connection to the established strategy. Missing full-method access blocks that execution; a generic funnel is not a replacement.

For downstream consumption, connect the model's intended perception and behavior changes to editorial encounters, actual stimuli, proof, friction, touchpoints and observable measures. Distinguish the desired future journey from observed behavior. Neither clicks nor follower counts alone measure a belief.

Use the publication's configured endpoint; understanding, experience, participation and return readership need not become a sale or subscription. Identity and journey share strategy as an upstream input, without a compulsory ordering between them.

Return JourneyContext, the intact original model, evidence gaps and concrete implications for the requested publication work. Route contradictions upstream with evidence instead of silently revising strategy. If no model is needed, record why and proceed with the editorial brief.

## Inputs and outputs

Inputs: StrategyContext; AudienceInsight; Publication-defined intended response; Authorized PFM dependency when a PFM is requested.

Outputs: JourneyContext; Full original method output if generated; Evidence and measurement gaps.

## Completion and learning

Check the delivered result against the current brief and the relevant evidence, technical and permission criteria above. Retain concise evidence of what worked, failed or remains unavailable in the private run record. Use media-learning for a justified reusable adaptation; current-output repairs do not automatically change the method.
