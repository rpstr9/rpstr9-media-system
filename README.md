# RPSTR9 Media System

Reusable methods to create, run and improve a publication. Each publication keeps its configuration, work and learning private.

## Start

Read [START_HERE.md](START_HERE.md), resolve the release through [releases/latest.json](https://raw.githubusercontent.com/rpstr9/rpstr9-media-system/main/releases/latest.json), and read the [complete master](dist/MASTER.md) plus the workflow needed for your request. Read all required sources at the resolved content commit. These files supply methods; your assistant, tools, accounts and private workspace supply execution. No model is pinned.

The library contains 20 skills covering publication creation, strategy, audience research, editorial selection, writing, creative direction, asset production, publishing, distribution, relationships, growth, measurement and private learning. Concept Review supplies researched expert perspectives between candidate concepts and concrete ideas, with revision, recheck and reuse of unchanged reviews. It is also available directly through [its complete skill](skills/concept-review/SKILL.md). Existing strategy and identity methods remain external dependencies: load their complete sources only when invoked. See [method dependencies](registry/method-dependencies.json).

This is an experimental edition. See [STATUS.md](STATUS.md) for execution scope and supported routes. Installation activates no service or account. Periodic operations can use a scheduled assistant with browser tools or a configured command executor; see the [private runner](runtime/reference/README.md) and [browser host procedure](runtime/reference/BROWSER_HOST.md).
